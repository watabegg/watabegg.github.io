rclone Privacy Policy

This OAuth application is used only by the site owner for personal file management with rclone.

Data accessed

The application can access Google Drive files and file metadata as required to mount and manage the owner's Drive from their personal computer.

Data use and storage

Google Drive data is processed only for file operations initiated by the owner. OAuth credentials are stored locally in the owner's rclone configuration. This application does not operate an independent server that collects or stores Google Drive data.

Sharing

Google user data is not sold or shared with third parties. rclone and Google process data as necessary to provide their respective services.

Revoking access

Access can be revoked at any time from the Google Account connections page or by removing the OAuth credentials from the local rclone configuration.

Contact

Questions about this application can be sent through the contact page.
