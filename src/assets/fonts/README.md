# Document fonts

ローカル文書のPDF生成を環境依存にしないため、Noto Sans JPを同梱しています。

- `NotoSansJP-Regular.ttf`：Google Fontsの `NotoSansJP[wght].ttf`（version 2.004、SHA-256 `c2f3b4d463500a2ddcd3849cded1fceeb9fd6d1c32e6cbecd568453ba50fc68f`）からweight 400を静的化し、Regularのname tableへ正規化したもの
- `NotoSansJP-Bold.ttf`：Noto Sans JP Bold version 2.004

Regularの生成後SHA-256は `a8f928b71dda97a695b01723002d442dbfbb38187749e5d50583c1cfaacdfd9e` です。配布元は [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosansjp)、ライセンスは `OFL-NotoSansJP.txt` を参照してください。
