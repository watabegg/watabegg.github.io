## 概要

友人のバンドで、FUJI ROCK FESTIVAL 2026に出演も果たしたバンド"二兆円"のホームページとオンラインストアを構築しました。メンバーからの要望を受け、その要求整理から実装、テストまでを一気通貫で行いました。

## 期間

2026-08-01/2026-09-01

## 使用技術

- TypeScript + Hono | 公式サイトのサーバーサイドレンダリングとAPIの実装
- React + Vite | バンドメンバー向け管理画面の構築
- Cloudflare Workers / D1 / R2 | アプリの実行、商品・注文データの管理、画像の保存・配信
- Drizzle ORM | データベースのスキーマ管理とクエリの実装
- Stripe Checkout | オンラインストアの決済処理
- Resend / Cloudflare Access | 注文・発送メールの送信と管理画面の認証

![二兆円ホームページ/管理者ページ アーキテクチャ図](/images/product/nichoyen-architecture.png)

## 業務領域

- メンバーへのヒアリング、要求整理、サイト構成と運用フローの設計
- 公式サイト、オンラインストア、管理画面の設計・実装
- 商品・在庫・注文・発送管理、ライブ情報・予約機能の実装
- 決済・メール通知の連携とデータベース設計
- テストの作成・実施、公開環境の構築、運用手順の整備

## 工夫点

1. 公開サイトはHonoでHTMLを生成し、ブラウザ側のJavaScriptを必要な操作に絞りました。Reactなどを使わないことでモダンサイトなのに`Wappalyzer`などで依存パッケージがCloudflare関係以外ほとんど確認できない不気味なサイトに仕上げました。
2. メンバーが過去グッズに利用した「二兆円語」を16種のビットマップフォントに落とし込み、UnicodeのPrivate Use Areaに当てはめて適当な規則で翻訳(多対一の暗号変換)する機能をつけました。かなり不気味な雰囲気を醸しています。
3. メンバーが自分たちで更新・運営できるよう、ライブや音源の掲載から、商品の登録、在庫・注文・発送の管理までを一つの管理画面にまとめました。
4. 決済完了の通知が繰り返し届いても注文が重複しないようにし、メール送信に失敗した場合の再試行も用意しました。購入後の処理まで含めて設計しています。
